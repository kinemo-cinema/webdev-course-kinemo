## [0.1.1] - 2026-11-07

### Added

- Added a StackBlitz configuration for opening the project in an interactive
  environment.

## [0.1.0] - 2026-11-07

### Added

- Added a six-lesson, beginner-friendly course introducing HTML and CSS through
  a Pokémon team page project.
- Added starter files and completed examples covering HTML structure, Pokémon
  cards, CSS styling, a six-card team page, and a debugging challenge.
- Added visual guides for lessons 1–5 and a course plan with lesson
  descriptions, activities, and learning resources.
- Added a README link to preview the final project.
