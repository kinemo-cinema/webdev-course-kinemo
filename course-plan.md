# Fundamentos de Desarrollo Web

## Resumen del Curso

Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. Al finalizar, cada estudiante habrá construido su propia página de **equipo Pokémon**. **¡No requiere descargas!** Solo abre tu navegador web.

- **Duración total:** ~60 minutos
- **Público objetivo:** Estudiantes de 12 a 17 años sin experiencia en programación
- **Prerrequisitos:** Ninguno
- **Herramientas necesarias:** **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)

## Secuencia de la lección

### Lección 1: ¿Qué es el desarrollo web? (5 minutos)

- **Descripción:** Aprende de qué están hechos los sitios web y por qué HTML y CSS son los componentes básicos. Vista previa del equipo Pokémon que construirás.
- **Enlace:** [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR)
- **Consejos clave:** Sitios web = Contenido (HTML) + Estilo (CSS).
- **Empieza a programar:** [Abrir CodePen](https://codepen.io/pen/editor/)

### Lección 2: Introducción a HTML (10 minutos)

- **Descripción:** Explora la estructura básica de una página y crea tu primera página con el nombre de tu Pokémon favorito.
- **Enlace:** [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR)
- **Consejos clave:** Usa `<html>`, `<head>`, `<body>`, `<h1>`, `<p>`.
- **Práctica:** [Clic para programar](https://codepen.io/your-username/pen/lesson2) — *¡No necesitas registrarte!*

### Lección 3: Añadir más elementos HTML (8 minutos)

- **Descripción:** Convierte tu página en una tarjeta de Pokémon con imagen, habilidad, estadísticas y movimientos.
- **Enlace:** [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR)
- **Consejos clave:** Usa `<img src="..." alt="...">`, `<ul>`, `<li>`, `<span>`, y `<a href="...">`.
- **Práctica:** [Clic para programar](https://jsfiddle.net/your-username/lesson3/) — *¡Comienza al instante!*

### Lección 4: Introducción a CSS (12 minutos)

- **Descripción:** Dale estilo a tu tarjeta de Pokémon con colores, fuentes y bordes redondeados.
- **Enlace:** [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR)
- **Consejos clave:** Vincula CSS con `<link>`, usa selectores de clase (`.card { ... }`), `border-top`, `border-radius` y `box-shadow`.
- **Práctica:** [Aplicar estilo con un clic](https://codepen.io/your-username/pen/lesson4) — *¡No es necesario registrarte!*

### Lección 5: Crear el equipo completo (15 minutos)

- **Descripción:** Combina HTML y CSS para crear tu equipo Pokémon completo con 6 tarjetas, usando `display: flex` y colores por tipo.
- **Enlace:** [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR)
- **Consejos clave:** Usa `<section>`, `display: flex`, `flex-wrap`, `gap`, y clases por tipo (`.card-fuego`, `.type-electrico`, …).
- **Proyecto final:** [Crea tu equipo](https://replit.com/@your-username/lesson5) — *¡Guarda y comparte!*

### Lección 6: Consejos y Próximos Pasos (10 minutos)

- **Descripción:** Encuentra y corrige 5 errores en una tarjeta de Pokémon. Mejores prácticas y dónde seguir aprendiendo.
- **Enlace:** [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR)
- **Consejos clave:** Valida tu código en validator.w3.org, revisa siempre cierres de etiquetas y atributos (`src`, `alt`).
- **Comparte tu trabajo:** [Reto: encuentra los errores](https://codepen.io/your-username/pen/lesson6)
